# TRADINGBOT-LAB

**Research-Only Laboratory Repository**

This repository is a **research-only laboratory** for trading strategy development, data analysis, and experimentation.

## Purpose

- ✅ **Research & Analysis**: Python modules, Jupyter notebooks, data analysis
- ✅ **Strategy Development**: Strategy research and optimization tools
- ✅ **Backtesting**: Historical data analysis and backtesting engines
- ✅ **Experimentation**: Safe experimentation without execution risk

## What This Repository Does NOT Contain

- ❌ **No execution code** - All execution logic lives in the TRADINGBOT repository
- ❌ **No live trading** - No connection to live exchanges
- ❌ **No environment setup** - No API keys, no exchange credentials
- ❌ **No exchange connectivity** - No real-time market data connections
- ❌ **No production systems** - No operator dashboards, no governance code

## Repository Structure

### Research Directories

- `python_api/` - Python API for research signals
- `modules/` - Python research modules (volatility, microstructure, sentiment, etc.)
- `notebooks/` - Jupyter notebooks for data analysis
- `optimizer/` - Strategy optimization tools
- `data/` - Historical market data (CSV files)
- `strategies/` - Strategy research files
- `reports/` - Research reports and analysis
- `docs/` - Documentation

### Analysis Tools

- `analyze-trading-results.js` - Analysis script (reads data only)
- `test-backtesting.js` - Backtesting test tool

### Quarantined Execution Code

- `_EXECUTION_QUARANTINE/` - All execution code has been moved here for reference only

## Usage

This repository is for:
- Developing and testing trading strategies
- Analyzing historical market data
- Running backtests
- Experimenting with new ideas
- Research and development

**All execution happens in the TRADINGBOT repository, not here.**
